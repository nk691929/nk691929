### Projects

**[Collaborative Inventory](https://github.com/nk691929/inventory-offline-sync-flutter)**
Offline-first Flutter inventory app with role-based access control enforced at both the UI and use-case layer, a Hive-backed sync queue with bounded retries and Last-Writer-Wins conflict resolution, and optimistic stock updates with automatic rollback on failure.

**[Lead CRM](https://github.com/nk691929/crm_app_n8n_flutter)**
Realtime lead-management dashboard: Supabase (Postgres, Auth, Realtime, Row Level Security) on the backend, n8n handling automated follow-ups, and a Flutter admin app enforcing real business rules on the lead pipeline — with a typed `Result`/`Failure` error layer, unit-tested use cases, and CI on every PR.

**[E-commerce Clean Architecture](https://github.com/nk691929/ecommerce-flutter-clean-arch)**
Full e-commerce browsing app against a live REST API — infinite-scroll pagination, debounced search, category filtering, a persistent cart, and `go_router`'s `StatefulShellRoute` with preserved tab state.

**[ApplyLog](https://github.com/nk691929/applylog-flutter)**
Job application tracker built on Firebase Auth and Firestore, with a `StreamProvider`-based auth state, `go_router` redirect logic for route protection, and scheduled local notifications for follow-ups.
